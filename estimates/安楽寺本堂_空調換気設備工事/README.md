## アラート（単価要確認）

- 機器は「推定（要確認）」として扱っています（定価 × 掛率の想定）。
- 室外機置台、換気の取付・ダクト・保温・外壁貫通・試運転は、エストに単価がないため当社単価（原価 × 1.25）で計上しています。ダクト等の原価は三矢寮で使った当社想定と同じです。
- 換気設備工事の部門内経費は、エストに規則がないため配管と同率（3%→5%→10%）を当社で設定しています。

## 要確認事項

1. 機器の仕入値（掛率）と、最新の価格表での定価の確認。三菱電機は 2027年1月1日に価格改定の予定です。
2. 施工場所（地番）。24時間換気の計算は 60Hz（中国電力管内）としています。
3. 天井高（24時間換気の計算とダクトの立上り）。
4. 室外機の設置場所（外陣の西側・和室(1)の北側・和室(2)と談話室の東側）と、AC-1 床置形と仏具の取合い。
5. 電気工事（空調 単相200V×5回路、換気扇 単相100V、24時間換気のスイッチ表示）は別途です。
