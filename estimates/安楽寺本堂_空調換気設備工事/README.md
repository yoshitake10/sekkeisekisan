## アラート（単価要確認）

- 室外機置台、換気の取付・ダクト・保温・外壁貫通・試運転は、エストに単価がないため当社単価（原価 × 1.25）で計上しています。ダクト等の原価は三矢寮で使った当社想定と同じです。
- 換気設備工事の部門内経費は、エストに規則がないため配管と同率（3%→5%→10%）を当社で設定しています。
