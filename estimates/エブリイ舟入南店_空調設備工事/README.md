## アラート（表紙内部欄・内訳書 K 列）

- **要見積 1件**: 二段置き架台（既製品か鉄骨製作品かで金額が大きく変わるため、既定は別途見積で金額 0）。
- **単価要確認 9件**: 別売品取付、冷媒回収、既設機器撤去、被覆銅管 6.35+12.70（メーカー価格×エスト比の推定）、分岐管取付、配管切廻接続、配線切廻接続、スリーブインサート（エスト 50,000円/4箇所の按分）、冷媒追加充填。エストに単価がないため当社単価（原価×1.25）または推定単価で仮計上しています。
- 前提: 空調機器は別途（支給または別途見積）、移設2台は天井吊形 P80 で既設室外機・既設配管を継続使用、立上り高さは想定値。

## 再生成

```bash
cd data
python3 takeoff.py <空調図.pdf> .    # 配管延長の再計測（takeoff.json と確認用 PNG を出力。PNG は案件フォルダへ移す）
python3 items.py                     # 数量（想定値を変えたとき）
python3 build.py                     # ワークブック作成 → 数式キャッシュ埋込 → 検算 → 提出用 PDF
```

`build.py` はワークブックの表紙金額と `est_book.simulate()` の計算が一致することを確認してから PDF を作ります。

## 要確認事項

1. 空調機器の扱い（支給か、当社で機器も見積るか）。
2. 二段置き架台の仕様と見積取得（メーカー既製品または鉄工所）。概算原価 300,000 円は仮置きです。
3. 移設2台の機種・形態（図示「80」から天井吊形 P80 と想定）と、既設室外機・既設配管の再利用可否。
4. 天井高・外壁開口の高さ、ドレンの屋外排出先。
5. 工程表の「機器取外し」に移設2台以外の撤去機器があるか。
6. 施工場所の住所（地番）。
