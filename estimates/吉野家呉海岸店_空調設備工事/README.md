- 宛名・件名・有効期間はエスト見積 No.6330560-1（2026年10月8日、今治空調設備 御中、本書有効期間10日）に合わせています。
- 図面: 換気空調機器表 F-01・空調設備図 F-02-1（1/50）・平面図 A-08。工程: 吉野家呉海岸通店新設工事 工程表（共栄店舗）

## 考え方（2026-10-08 改定）

1. **単価はエストに合わせる。** 内訳書はエスト見積 6330560-1 と同じ並び・同じ単価です。継手類・消耗品・支持金物の率、配管工費の算式、部門内経費・工事諸経費の積上げ規則もエストから逆算して合わせました。エストの数量を入れると各計が一致することを `data/simulate.py est` で確認しています。
2. **提出額は出精値引で決める。** 原価合計を（1－目標粗利率20%）で割り、1万円単位で切り上げた額を提出額とし、小計との差を出精値引に計上します。
3. **エストに単価がない項目はアラート。** 鉄骨架台は「要見積」（赤）で、既定では別途見積として金額に含めません。概算原価は内部欄に保持しています。ドレン逆止弁は「単価要確認」（橙）として当社単価で仮計上しています。
4. **原価は公表データを基準にする。** 材料はエスト材料単価を建設物価相当として採用しました。建設物価は会員制で数値が取れず、自治体の公表単価表でも冷媒管・保温は非公表です。エスト単価はメーカー公表価格の約6割で実勢価格の水準です。人工は国交省の公共建築工事標準単価積算基準（令和8年改定）の歩掛で、労務原価日額は当社19,000円です。公共工事設計労務単価（令和8年3月・広島 配管工24,700円）での感度も表紙内部欄に出しています。

## ワークブック構成

| シート | 用途 |
|---|---|
| 表紙(工事) | エスト形式の表紙（空調設備機器 支給品／空調設備工事／配管設備工事／工事諸経費／小計／出精値引／合計、法定福利費相当額の内含表示）。M〜Q列は内部の設定・原価集計・アラート・感度 |

| 御見積条件 | 条件・想定数量の前提・図面読み取りの確認事項 |

変更増減は内訳書のエスト単価×増減数量に経費を載せ、出精値引率（表紙内部欄）を乗じて算定できます。


## 要確認事項

1. エストの SA 室外機が2台になっている点（図面は3台）。エストを直すか、当社の3台で提出するか。
2. 鉄骨架台の見積取得（鉄工所またはメーカー）。概算原価 300,000／250,000 円は仮置きです。
3. 材料の仕入価格（建設物価との照合）。表紙 N7 の材料原価率で調整できます。
4. 法定福利費の料率。エストは 16.04%、本書は令和8年度料率の合計 16.375% です。
5. 施工場所の地番。
