## ルール

**単価（提出側）** は次の順で決めます。

1. エスト見積 No.6330560-1 の単価
2. エスト単価マスタ（容量別の搬入据付・基礎など）
3. どちらにもない材料は、メーカー公表価格 × エスト比率（約0.60）で推定し、「単価要確認（推定）」のアラートを出します。
4. 労務だけの項目は当社単価（原価 × 1.25、100円切上げ）とし、「単価要確認」のアラートを出します。
5. 鉄骨架台など情報が少ない製作品は「要見積」（赤）にします。既定では別途見積で金額 0 とし、概算原価は内部欄に持ちます。

**エストの計算規則**

- 冷媒管の継手類・消耗品・支持金物は管金額の 30%・15%・40%、塩ビ管は 20%・10%・25% です。
- 配管工費は、国交省 公共建築工事標準単価積算基準（R8）の歩掛 × 33,750円/人 で、10円未満を切り上げます。
- 電線材料施工費は 0.017人/m × 33,600円/人 です。
- 部門内経費は、空調が 3%→4%→8%、配管が 3%→5%→10% の順に積み上げます。それぞれ100円未満を切り上げ、計の1,000円未満は現場経費で切り上げます。
- 工事諸経費は（空調＋配管）× 5% です。

**提出額** は、原価合計 ÷（1 − 目標粗利率 20%）を1万円単位で切り上げた額です。小計との差を出精値引に計上します。法定福利費は工事費に内含して表示します（Ａ＝Ｙ×Ｚ）。

**原価**

- 材料は、エスト材料単価を建設物価相当として採用し、材料原価率と管長割増（被覆銅管 1.05、VP 1.10）を掛けます。
- 労務は、人工 × 19,000円 です。人工は、配管・電線が国交省歩掛、据付などが当社想定です。
- 法定福利費（事業主負担）は、労務原価 × 16.375%（令和8年度）です。

## 新しい物件の作り方

1. `../<物件名>/data/` に図面の数量（`items.py` など）と `job.py` を作ります。`job.py` に必要な属性は `est_book.py` 冒頭の説明を参照してください。エブリイ舟入南店の `job.py` が見本です。
2. 明細の行は `kind` で書きます。
   - `item`: `cat=` でカタログの単価・出典を引きます。エストにない労務項目は `src=R.SRC_OWN` と `mat`・`md` を指定すると、当社単価が自動で入ります。
   - `tbd`: 要見積です。`prov` に概算原価を入れます。
   - `pct`: 率の行です。`labor`: 配管工費・電線材料施工費です。`exp`: 部門内経費です。
3. `build.py`（エブリイ舟入南店のものをコピー）を実行すると、ワークブック作成 → キャッシュ埋込 → 検算 → PDF まで進みます。
4. 新しいエスト見積やマスタの単価が手に入ったら、`est_rules.py` の `CAT` に追加します。

## 部門の構成（空調・換気を1冊にする場合など）

部門（`SECTIONS` の各要素）は2つに限らず、何部門でも並べられます。表紙の①②…は部門の順に自動で振られます。安楽寺本堂が見本です。

- 機器を材工で計上する場合は、`EQUIP_ROW = None` にして、機器の部門を `oh=False`（工事諸経費の対象外）で置きます。部門内経費の行（`kind='exp'`）を入れなければ、部門内経費は付きません。
- 機器の行は**原価基準**で書きます（安楽寺本堂の `job.py` の `eq()`）。原価は `mat=定価×仕入率`（定額）、単価は `price=原価÷(1−目標粗利率)` を10円未満で切り上げた額です。単価区分は「原価基準（仕入率）」で、アラートは出ません。仕入率の目安は、ダイキン業務用（EcoZEAS・FIVESTAR）20%、ダイキン家庭用（定価あり）30%、三菱電機の換気機器 32%（2026-10-09 確認）です。
  - 原価を提出単価に連動させたい場合は、`mat=('EQ', 仕入率÷提出率)` も使えます（L列＝単価×材料原価率×比）。
- 機器を原価基準で計上したときは、表紙内部欄の注記（`COVER_INTERNAL_NOTES`）にその旨を書いておきます。
- 換気設備工事の部門内経費は `exp_key='VENT'` で指定します（配管と同率 3%→5%→10% を当社で設定）。
- そのほかの任意設定: `WORK_TITLE`（表紙の工事種別）、`OH_NO`（工事諸経費の番号）、`WF_EQUIP_TXT`（法定福利費の注記）、`break_after`（部門ごとの改ページ）、`SRC_RULE_NOTES`（単価出典シートの追加規則）。
- 既存の2部門の物件（エブリイ舟入南店）は、改修の前後で出力が全セル一致することを確認しています。
