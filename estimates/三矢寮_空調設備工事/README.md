## 粗利の仕組み

- 各明細の **基準単価 = 材料単価 + 労務単価**（想定原価、黄セル）。**提出単価 = ROUND(基準単価 × 提出係数, -1)**。
- 提出係数は表紙 `N4`（定義名 `COEF`）。1.10 → 行粗利率 9.1%、1.25 → 20%。行ごとに変える場合は内訳書 M 列に直接入力。
- 表紙内部欄に 原価合計（法定福利費は原価＝提出値、諸経費は原価なし）、粗利、粗利率、および粗利率 10〜30% の参考提出額と必要提出係数。
- 法定福利費 = 内訳書 O 列（数量×労務単価×係数）の合計 × 料率合計 16.375%（保険ごとに円未満切捨て）。
- 金額は全て数式。キャッシュ値埋込済（Excel で開けば再計算）。

## 数量の拾い方（実測／推測）

- **実測**: PDF 図面のベクトル線分を色・線幅で分離し、A3 1:300（厨房詳細 1:70）で平面延長を機械集計。冷媒管＝黒線、ドレン管＝青線、EA ダクト＝黒太線、OA ダクト＝青線。口径はラベル最近傍で割当。
- **推測**: 立上り・立下り（PAC 4 m/系統、RAC 3 m/台）、RAC-3（2F 寮室 66 台、配管線なし）4 m/台、追AC1〜5（配管経路の図示なし）は室内外機位置から推定。
- 内訳書 P 列（内部）に根拠区分、御見積条件【2】に推測項目の前提を列挙。
