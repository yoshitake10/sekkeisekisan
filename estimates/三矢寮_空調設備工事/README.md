## 数量の拾い方（実測／推測）

- **実測**: PDF 図面のベクトル線分を色・線幅で分離し、A3 1:300（厨房詳細 1:70）で平面延長を機械集計。
  - 冷媒管 = 黒線 w0.6（機器記号は矩形・菱形除去）、ドレン管 = 青線、EA ダクト = 黒線 w0.72、OA ダクト = 青線。
  - 口径はラベル（25/40、100〜300）への最近傍割当。未割当分は比例配分または 150φ に計上。
- **推測**: 立上り・立下り（1F 地上室外機→天井 4 m/系統、RAC 3 m/台）、RAC-3（2F 寮室 66 台、図面に配管線なし）4 m/台、追 AC1〜5（配管経路の図示なし）は室内外機位置から経路長を推定。
- **図面カウント**: 機器台数、制気口、VD、区画貫通部（●）など。
