## 原価と粗利の仕組み（宮地機工 参考見積8件から整理）

- **原価 = 材料原価 ＋ 人工 × 労務原価日額（表紙 N8＝19,000円/人工）**。内訳書の黄セル J（材料原価）・K（人工/単位）を直すと全体が連動します。
- **提出単価（定価ベース）= 原価 × 提出係数（表紙 N4＝1.22）**。1.22 は参考見積の人工単価 23,225円/人工（6330476-3 配管工費 40人工 929,000）と材料定価（継手30%＋消耗15%＋支持金物40%込）に合わせた値です。
- **諸経費 22%**（表紙 N5）= 参考見積の部門内経費（消耗雑材 2.6%＋資材運搬 3.5%＋現場経費 7.4% ≒ 15.7〜19%）＋ 工事諸経費 5% 相当。
- **出精値引き**: 表紙 N9「目標提出額」を入れるとその額に合わせます。空欄なら N6 の単位（10万円）未満を切り捨て。
- **法定福利費** = 内訳書 P 列（数量×労務原価×提出係数）の合計 × 料率 16.375%（参考見積は 16.04% で金額内含と注記）。
- 内訳書の内部列: J 材料原価・K 人工・L 労務原価・M 基準原価単価・N 提出係数・O 基準原価・P 労務費(提出)・Q 数量根拠・R 粗利・S 粗利率・**T 参考定価ベース単価・U 当社/参考**（参考見積に同種項目がある行のみ）・V 単価出典。
- 表紙内部欄: 原価合計・労務費・粗利・粗利率、粗利率 10〜30% の参考提出額と必要提出係数。
- **単価マスタ(内部)** シート: 全単価キーの材料原価・人工・原価・提出・参考定価ベース・出典。ダクト・制気口・フード類は参考見積に実績がないため当社想定（出典欄に明記）。

## 数量の拾い方（実測／推測）

- **実測**: PDF 図面のベクトル線分を色・線幅で分離し、A3 1:300（厨房詳細 1:70）で平面延長を機械集計。冷媒管＝黒線、ドレン管＝青線、EA ダクト＝黒太線、OA ダクト＝青線。口径はラベル最近傍で割当。
- **推測**: 立上り・立下り（PAC 4 m/系統、RAC 3 m/台）、RAC-3（2F 寮室 66 台、配管線なし）4 m/台、追AC1〜5（配管経路の図示なし）は室内外機位置から推定。
- 内訳書 P 列（内部）に根拠区分、御見積条件【2】に推測項目の前提を列挙。
