## 範囲の判断（要確認）

- **室外機架台・基礎・防振ゴム**は、特記「空調室外機の基礎、鉄骨架台（防振ゴム）（空調設備工事）」と室外機設置概要図「鉄骨架台は本工事/空調工事」により ⑤室外機設置 に含めました（架台 339,160・基礎 59,780・防振ゴム 21,480）。不要なら行を削除してください。
- **外部配管化粧カバー・外壁貫通**は、特記「外部冷媒配管は断熱材巻の上、カラー鉄板ラッキングまたはスリムダクト」により ②冷媒配管 に含めました（85,220）。

## 再生成

```bash
cd data
python3 takeoff_f02.py <換気空調機器表.pdf（2ページ目が F-02-1）> .   # 数量の再計測（takeoff_f02.json と根拠画像）
python3 build_yoshinoya.py <出力先>                                   # 明細は items.py、単価は pricing.py
python3 recalc_cache.py <出力先>/御見積書_*.xlsx                       # 数式キャッシュ値の埋込（.values.json も出力される）
python3 make_pdf.py <出力先>/御見積書_*.xlsx <出力先>                  # 内部シートを除いて PDF 化（LibreOffice）
```

## 要確認事項

1. 宛名（元請）・見積 No.・施工場所の地番
2. 室外機架台・基礎・防振ゴム、外部化粧カバー・外壁貫通を本見積に含めてよいか（上記「範囲の判断」）
3. 渡り操作配線・リモコン取付、試運転調整を誰が行うか（図面特記は空調設備工事）
4. 架台は既製品相当の想定単価（要メーカー見積）。ダイキン室外機 H1,430 に対応する段間寸法
5. 特記「耐熱ポリスチレンフォーム」は冷媒管用の耐熱ポリエチレンフォーム（厚20mm）と解釈
6. ドレン逆止弁 NDB-20-25 の施工区分（本見積に計上、給排水側なら減額）
