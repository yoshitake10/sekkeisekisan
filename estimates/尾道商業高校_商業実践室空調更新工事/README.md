## 仮定・要確認

1. **アスベストの内訳（※）**: 見積書は「アスベスト事前調査 1式 75,000」だけなので、様式の 5 行に
   検体調査 22,000×2・現場収集 8,000×2・雑材 3,000・運搬 5,000・現場雑費 7,000 で仮に割り付けた。
   調査会社の見積内訳があれば `data/build_uchiwake.py` の `ASBESTOS_SPLIT` を差し替えて再生成する。
2. **重機費（高所作業車）**: 様式の名称は高所作業車だが、見積はレッカー等の揚重費。名称は様式のまま、規格欄に「揚重（レッカー等）」と記載。
3. **工事諸経費 37,500** は様式に行が無いので ② 現場雑費 に含めた（規格欄に「現場経費・工事諸経費」）。
4. **内外連絡線（VVF 2.0-3C）・ドレン管** は見積書で配管設備工事に入っているので ② 冷媒配管工事費 に含めた。
5. **消費税** 欄は空欄だったので `=ROUNDDOWN(H36*0.1,0)`（10%）を入れた。
6. 様式の E3（タイトル右の下線欄）に「見積番号 6330515-2　宮地機工株式会社」を記入。
7. 印刷設定を「1 ページに収める」に変更（元の 83% 固定だと環境によって 2 ページに分かれるため）。
   それ以外の様式（罫線・フォント・秘密度ラベル等）は変更していない。
8. 値引按分版は工事費（労務分）も同率で下がるため、見積書に記載の「法定福利費相当額 29,016 円」とは厳密には対応しない。

## 再生成

```bash
cd data
python3 build_uchiwake.py ..        # 2 案の xlsx を出力（明細の検算・振り分け漏れチェック付き）
cd .. && soffice --headless --convert-to pdf 工事内訳書_*.xlsx   # プレビュー PDF（任意）
```
