印刷範囲 `A1:L43`（A4 縦・1 ページに収める設定）。M〜T 列は社内用（印刷されない）。

## 明細欄（行 19〜43 が 1 つの枠）
| 行 | 内容 |
|---|---|
| 19 | 見出し: 項目 ／ 内容(B:F 結合) ／ 数量 ／ 単位 ／ 単価(I:J 結合) ／ 金額 ／ 備考。M〜S は社内列の見出し |
| 20 | 【タイトル】行 |
| 21〜 | 明細行（A: ①②…、B: 名称、G: 数量、H: 単位、I: 単価、K: 金額） |
| 合計行 | B「　合　　計」、K `=SUM(...)`（行高 25.5） |
| 39〜40 | 注記（「・本見積書に記載なき事項については…」「・工事に係る電気・水道は…」）— 触らない |
| 41〜43 | 空行（43 が枠の最下段・下罫線） |

表紙に直接書けるのは **タイトル行＋明細 16 行＋合計行**（20〜38 行）まで。超える場合は `内訳(工事)` シートを新設し、表紙には区分ごとの集計行（`=SUM('内訳(工事)'!K..)`）を置く。

## 行の「型」と流用元（書式 = セルの style id をテンプレートからコピー）
| 型 | 流用元の行 | 用途 |
|---|---|---|
| title | 20 | 【…】見出し |
| section | 21 | ［…］区分見出し |
| item | 22（B〜F は 24 行目の折返し無し書式、P は整数書式） | 明細 |
| total | 28 | 合計（行高 25.5） |
| blank | 41 | 空行 |
| last | 43 | 枠の最下段（下罫線が太い）。内訳シートの合計行に使う |
| header / spacer | 19 / 18 | 内訳シートの見出し行・余白行 |

## 社内列（M〜T、印刷されない）
| 列 | 見出し | 明細行の中身 |
|---|---|---|
| M | 粗利率(%) | `='表紙(工事)'!$N$9`（表紙なら `=$N$9`）。直接入力で行ごとに上書き可 |
| N | 数量 | `=G` |
| O | 原価単価 | 元見積の単価（無い行は 金額÷数量 が割り切れるときだけ） |
| P | 掛率(%) | `=$N$10` 参照。直接入力で上書き可 |
| Q | 粗利額 | `=K−R` |
| R | 原価金額 | 元見積の金額 |
| S | 備考 | 元見積の備考 |

設定セル（表紙 M8:N15、M6:T18 の枠内）: `N9` 粗利率(%)、`N10` 掛率(%)、`N11` 端数処理(円)。黄色塗り。

## 内訳(工事) シート（明細が多いときだけ生成）
- 列幅・余白・フッター（社名）は表紙と同じ。印刷は横 1 ページに収め、縦は必要ページ数。7 行目を各ページに繰り返す
- 1〜2 行: 「内　訳　明　細　書」、3 行: No.（表紙参照）、4 行: 工事名（表紙参照）、5 行: 宛名（表紙参照）
- 8 行: 【タイトル】、9 行〜: 区分見出し／明細（A 列は 1,2,3… の通し番号）、最終行: 合計
