# 空調換気設備 設計積算ツール

空調・換気設備工事会社向けの、ブラウザ完結型の設計積算ツールです。
図面からの拾い出し・負荷計算にもとづくダイキン機器の選定・数量表の作成・概算/詳細見積書の作成までを1つのアプリで行えます。

## 主な機能

### 1. 図面拾い（PDF / DXF）
- **PDF平面図**: ページ表示・ズーム・パン。2点指定＋実寸入力でスケール設定し、
  - 個数カウント（室内機・室外機・吹出口 など）
  - 長さ拾い（角ダクト・スパイラルダクト・冷媒配管・ドレン配管 など）
  - 面積拾い（部屋面積）
- **DXF(CAD)平面図**: 図面単位（mm/cm/m）指定または2点実測でスケール設定。線分端点へのスナップ付き長さ拾い、ブロック(INSERT)名ごとの自動集計。
- 拾い結果はワンクリックで数量表へ転記できます。

### 2. 数量表
- 手入力・図面拾い・機器選定・Excel/CSV取込の4系統を一元管理（出典バッジ付き）。
- **数量表Excel/CSVの取込**: シート選択→列マッピング（名称/規格/単位/数量/単価…）で既存の数量表をそのまま取り込めます。
- 単価マスタからの一括単価引当（名称+規格 完全一致→名称一致→部分一致）。
- Excel書出し対応。

### 3. 機器選定（負荷計算）
- 部屋ごとに用途・面積・天井高を入力すると、用途別の**冷房負荷原単位（W/m²）**から必要能力を計算し、**ダイキンの機種を自動選定**します（余裕率・台数分割・形態指定・手動変更可）。
- 換気は「換気回数×室容積」と「人員×30m³/h」の大きい方から必要換気量を求め、全熱交換器ユニット（ベンティエール）を選定します。
- 選定結果は台数を集約して数量表へ転記できます。

### 4. 見積書
- **概算見積**: 用途×面積×概算単価（円/m²）だけで即時に概算見積書を作成。案件情報や機器選定の部屋一覧から自動生成も可能。
- **詳細見積**: 数量表×単価から、分類別内訳→直接工事費→諸経費→法定福利費→端数調整（出精値引）→消費税まで自動計算。
- A4見積書プレビュー（表紙＋内訳明細）、ブラウザ印刷（PDF保存）、Excel書出し。

### 5. マスタ管理
- **単価マスタ**: お手持ちの複合単価表・見積実績のExcelを列マッピングで取込み、自社単価として利用。
- **ダイキン機器DB**: スカイエア（ZEAS各形態×馬力）、VRV室外機/室内機、全熱交換器ベンティエールを収録。定価・型番は編集可能。
- **原単位・概算単価**: 用途別の負荷原単位・換気回数・概算平米単価を自社基準に編集可能。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 本番ビルド (dist/ に静的ファイル生成)
npm run preview  # ビルド結果の確認
```

ビルド成果物（`dist/`）は静的ファイルのみなので、社内ファイルサーバーやイントラのWebサーバーに置くだけで利用できます。データはブラウザ（localStorage）に自動保存され、案件ごとにJSONで書出し/読込みできます。

## 技術構成

- Vite + React 18 + TypeScript（完全クライアントサイド・外部通信なし）
- PDF表示: [pdfjs-dist](https://github.com/mozilla/pdf.js) / DXF解析: dxf-parser / Excel入出力: SheetJS(xlsx) / 状態管理: zustand

## 注意事項

- 収録している機器データ（型番・能力・定価）は代表的なカタログ値にもとづく**目安**です。正式見積の際は必ず最新のメーカーカタログ・仕切り価格をご確認ください。
- 負荷原単位・概算単価の初期値は一般的な設計目安です。受注判断に使う場合は必ず自社実績で補正してください。
- データはブラウザごとに保存されます。PC入替え・ブラウザ変更の際はプロジェクトのJSON書出しで移行してください。
