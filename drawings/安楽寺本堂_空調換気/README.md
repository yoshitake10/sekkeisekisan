# 安楽寺 本堂 新築工事 空調・換気設備図

意匠図（松森設計事務所 平面図 令和8年7月20日版の JWW）をベースに、空調・換気設備を Jw_cad 形式で作図したものです。

| ファイル | 内容 |
|---|---|
| `M-1_空調設備平面図.jww` / `.pdf` / `.dxf` | 空調機の配置、冷媒・ドレン配管、空調機器表、凡例・特記 |
| `M-2_換気設備平面図.jww` / `.pdf` / `.dxf` | 24時間換気（EF-1）、給気口、局所換気、ダクト、換気経路、換気機器表、24時間換気計算表、シックハウス特記 |
| `24時間換気計算書.xlsx` / `.pdf` | シックハウス対策 24時間換気計算書（建築基準法施行令第20条の8）。黄色セルを変えると再計算されます |
| `source/平面図_8-20_da3-100.jww` | ベースにした意匠平面図（原本） |

## JWW の構成

- 建築ベースはレイヤグループ 0・1 に原本のまま残しています。設備はレイヤグループ 2 に追記しました（書込みグループも 2 に設定済み）。
  - M-1 グループ「空調設備」のレイヤ：0 室内機、1 室外機、2 冷媒配管、3 ドレン配管、4 記号・文字、5 機器表、6 凡例・特記
  - M-2 グループ「換気設備」のレイヤ：0 換気扇(24h)、1 換気扇(局所)、2 給気口、3 ダクト・フード、4 換気経路、5 記号・文字、6 機器表、7 計算表・特記
- 縮尺は原本と同じです（JWW 上は A1・1/50 で、A3 に出力すると 1/100）。
- 表題欄の図面名称は「空調設備平面図 M-1」「換気設備平面図 M-2」に変更しています。

## 設計内容

- **空調**：8月10日付の検討最終VE案「提案① ダイキン」で作図しています。
  - AC-1：SZRV80BZV（床置形）×2台（大間・外陣）
  - AC-2：S284ATEV-W ×2台（和室(1)・和室(2)）
  - AC-3：S404ATEV-W ×1台（談話室）
- **24時間換気**：第3種機械換気で、全館を一体として換気します。
  - 排気：EF-1 パナソニック FY-17C8 ×3台（便所(女)・小便所・便所(男)）、常時運転
  - 必要有効換気量 Vr ＝ 185.1 m³/h、有効換気量 Ve ＝ 80.5 × 3 ＝ 241.5 m³/h で、Ve ≧ Vr を満たします（1.30倍）
  - 換気回数は、本堂部（外陣・内陣・護摩堂）を 0.3 回/h、庫裏側（和室・談話室ほか）を安全側に 0.5 回/h としています
- 換気機器の種類は、パナソニックの換気システムご提案書（当初プラン）に合わせています。配置は現行の平面図に合わせて置き直しました。

## 要確認事項（確認申請前）

1. **天井高は仮定値です**（外陣 3.3m、内陣 3.6m、護摩堂 3.3m、広縁 2.7m、その他 2.4m）。矩計図が確定したら、計算書の黄色セルに入力して再計算してください。本堂部の天井高が 5.38m 以下であれば、現計画のまま適合します。
2. 床面積は平面図の壁芯から読み取った値です。旧VE表の面積（13.11㎡ など）は旧プランの値なので、使っていません。
3. 天井裏等の措置（令20条の9）は「建材による措置（F☆☆☆以上）」として記載しています。意匠の仕様と合わせてください。
4. 室外機の組合せ型番・外形寸法と、FY-17C8 の P-Q 特性は、承認図・メーカー技術資料で最終確認してください。
5. 建築場所と設備設計者の欄は空欄です（計算書の黄色セル）。

## 再生成

```sh
JP_TTF=/path/to/ipaexg.ttf drawings/tools/build_all.sh   # PDF に日本語フォントを埋め込む
```

- `drawings/tools/jww.py` は JWW（Ver.7.00 形式）の読み書きモジュールです。原本を読み込んで書き出すと、バイト単位で完全に一致することを確認しています。
- 室データ・機器データ・配置座標は `drawings/tools/project_data.py` にまとめています。ここを変更して `build_all.sh` を実行すると、図面と計算書が両方とも更新されます。
